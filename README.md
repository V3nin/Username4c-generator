# Username4c-generator
🔤 4C Username Generator  A simple and efficient 4-character username generator, developed by me.  This project generates short, clean, and unique usernames made of 4 characters, combining selected letters and digits to create compact and hard-to-guess names.  The generator is designed for:  Gaming usernames  Social media accounts  Automation and testing  Username availability checks  Features  Random 4-character username generation (4C)  Uses custom letter and digit sets  Automatic clipboard copy  Optional auto-paste and replace functionality  Infinite generation loop  Lightweight and easy to use  This tool is ideal for anyone looking for short, modern, and rare usernames.
